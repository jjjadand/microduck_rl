# Jetson Demo Media

These screenshots and screencasts were captured on the Jetson device used to
reproduce the Microduck training and inference demo.

## Screenshots

- `screenshots/training_metrics.png` — PPO iteration metrics and reward terms.
- `screenshots/training_configuration.png` — active reward, curriculum, actor,
  and critic configuration printed at startup.
- `screenshots/jetson_gpu_monitor.png` — Jetson GPU, memory, power, and thermal
  monitoring during training.
- `screenshots/parallel_training_environments.png` — multiple Microduck
  environments rendered in parallel.
- `screenshots/mujoco_viewer_front.png` — native MuJoCo front view.
- `screenshots/mujoco_viewer_side.png` — native MuJoCo side view.

## Videos

- `videos/walking_forward.mp4` — forward velocity inference test.
- `videos/walking_reverse.mp4` — reverse velocity inference test.
- `videos/keyboard_ball_kick.mp4` — keyboard-triggered ball-kick policy test.

The MP4 files use H.264 video with `yuv420p` pixel format for browser playback.
